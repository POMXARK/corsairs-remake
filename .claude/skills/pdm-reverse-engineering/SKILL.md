# Декомпиляторы и инструменты реверса: что и когда

Цель всех инструментов одна: понять, *что делает* оригинал, и перенести правило в конвертер или скрипт своими словами. Декомпилированный код Akella в git не попадает (`$W/ref/` локально). Закрытые утилиты j88-yo не используются, только справка по форматам.

Перед работой прочитайте `docs/decompile.md` (полный порядок поиска на примере стен и горожан) и `docs/pdm-formats.md` (форматы).

## Выбор инструмента

| Вопрос | Инструмент | Пример |
|---|---|---|
| Какая функция в DLL отвечает за поведение, и какие в ней константы | Ghidra headless → `ref/pdm-decomp/<dll>.c`, grep | «почему герой не заходит в стену» (`MAN.dll`) |
| Точечный вопрос к одной функции, строке или адресу | REA CLI (skill `rea-cli`) | `function MAN.dll main`, `xrefs` на строку |
| Значение константы по адресу из Ghidra | `tools/pe_const.py <dll> <адрес>` | `1000c200` → float, double, int |
| Сравнить с другой сборкой или проверить, что правило не менялось | REA `compare`, `evidence-import` | две версии DLL |
| Формат файла действий `.a` | `tools/a_decode.py <file.a \| dir>` | поворот байтов в блоках по 8 |
| Текстура `.tf` оригинала | `tools/tf2tx.py` | `.tf` → `.tx` (TXF_A8R8G8B8) |
| Структура геометрии `.gm` движка | `tools/gm_inspect.py <file.gm>` | почему модель не грузится или не видна |
| Анимации `.an` / `.ani` после конвертации | `tools/pdm_anim_check.py` | рывки, неверные кадры |
| Падение движка: минидамп | `tools/parse_dump.py` | исключение, контексты потоков, загруженные модули |
| Падение движка: адреса в стеке | `tools/resolve_crash_stack.py` | адреса стека → строки `engine.exe` |

## Ghidra headless: полная выгрузка модуля

Когда нужно искать по всему модулю, а не по одной функции. Запуск долгий (около 40 минут на 104 модуля), поэтому в фоне:

```bash
W=/media/roman/383be9ee-c114-4bf8-8956-66b985661cb4/home/remake-linux
PDM=/media/roman/383be9ee-c114-4bf8-8956-66b985661cb4/home/Корсары
JAVA_HOME=/usr/lib/jvm/jdk-24.0.1-oracle-x64 GHIDRA=$W/tools/ghidra_12.1.4_PUBLIC \
  corsairs-remake/tools/ghidra/decompile.sh $W/ref/pdm-decomp $PDM/MODULES/MAN.dll
```

Результат: `<dll>.c` (функции с адресами в комментариях), `<dll>.strings.txt` (строки с адресами), `<dll>.log`.

Если анализ не нашёл функцию (её зовут только через виртуальную таблицу), передайте адреса через `ENTRIES="100032e0 10003f10"`. Адреса берутся из таблицы в `.rdata`, на которую ссылается конструктор.

Поиск в выгрузке:

```bash
cd $W/ref/pdm-decomp
grep -v "R60\|Heap\|KERNEL" MAN.dll.strings.txt | tail -80   # имена анимаций, файлов, ключей
grep -n "1000d0f0" MAN.dll.c                                 # функции, которые используют адрес строки
grep -n "0\.3\b" MAN.dll.c                                   # функции с характерной константой
```

## Ограничения, которые надо помнить

- Имён нет. Смысл поля (`param_1 + 0x22c7c` — скорость) выводится из того, как поле используется. Записывайте вывод как гипотезу и проверяйте на игре.
- Вызовы между DLL идут через виртуальные таблицы `CORE.dll`. Метод по смещению (`+0x80`) сопоставляется вручную.
- Короткие строки (меньше 5 символов, например `KILL`) в выгрузку Ghidra не попадают. Их ищут прямо в данных DLL, по таблицам указателей в `.data`.
- `tools/pe_check.py` содержит жёсткий путь `C:\corsairs-remake\…`. Перед запуском поправьте путь на свой.
- Ghidra на Windows через REA только для чтения.

## Чеклист перед переносом правила в игру

1. Правило найдено в функции, константы прочитаны через `pe_const.py`, а не угаданы.
2. Записано в `docs/original-vs-remake.md` или `docs/pdm-formats.md` своими словами, без кода Akella.
3. Перенесено в конвертер (`tools/pdm_*.py`) или скрипт, и проверено автотестом из `docs/test-commands.md`.
4. Если правило оказалось неочевидным, оно записано в `docs/decompile.md` (раздел «Что так уже найдено»).
