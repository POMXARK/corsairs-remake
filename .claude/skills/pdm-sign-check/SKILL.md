# Вывески городов (pdm-game)

Вывеска — доска из силуэта альфы (`tools/pdm_props3d.py`): лицо и оборот с одной картинкой, оборот зеркален вдоль доски, текст читается с обеих сторон. Лежит в своей модели `<город>_signs.gm`. Подробности — `docs/pdm-formats.md` (вывески), `docs/autotests.md` (вывески с обеих сторон).

## Правила
- Вывеска — текстура `viveska_*`, а в английском Хайроке `tavern`, `ship_yard`, `store` (`SIGN_NAMES`). Новый город: сначала найти имена квадратов без `land*`, не деревьев, и добавить в `SIGN_NAMES`.
- Города целиком не пересобирать (BSP — минуты): `python3 -I tools/pdm_world.py <Корсары> pdm-game --signs [City_…]` (~20 с на город). Старые плоские спрайты остаются в `city_*.gm` внутри доски и не видны.
- Успех — только по кадрам: текст читается с обеих сторон. Не по логу.

## Шаги
1. Найти вывески и CAM каждой стороны: `python3 -I tools/pdm_signs_find.py <Корсары> City_HighRock`.
2. Кадры: `pdm-game/sign-shots.sh build/Debug/engine /tmp/signs <Корсары> City_HighRock` → `/tmp/signs/<город>-<текстура>-<n>.jpg` (+1 и −1 рядом). Склеить `ffmpeg … hstack`, посмотреть глазами.
3. Одна сторона вручную: `TOWN=City_HighRock CAM=cx,cy,cz,hx,hy,hz SCENE=town TOWN_AUTO=50 pdm-game/run.sh build/Debug/engine`.
4. Автотесты: `pdm-game/autotests.sh build/Debug/engine sign-tavern-front sign-tavern-back …` (модель загружена, `error.log` пуст).

## Подводные камни
- Оборот зеркалится у грани нормали (`if side: u = 1 - u` в `sign_mesh`): левосторонняя система движка. Обратная раскладка даёт зеркальный текст с обеих сторон.
- `TOWN_AUTO=50` выходит через 22 с: раньше запись (`x11grab`) не успевает стартовать. «Failed to translate xcb geometry» — повторить, `sign-shots.sh` повторяет сам.
- Скрипты не читают stdin нужным образом: цикл по выводу `pdm_signs_find.py` вызывает `shots.sh` с `< /dev/null`, иначе запись съедает остаток списка.
