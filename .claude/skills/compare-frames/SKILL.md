# Коллажи кадров для сверки с оригиналом

**Зачем.** Эффекты, вода и камера оцениваются только по картинке: числа и код не показывают, «похоже ли». Коллаж «оригинал слева, моё справа» в один кадр позволяет сразу увидеть расхождения (положение эффекта, размер, цвет, уровень воды, осадку) и не гонять пользователя по каждой правке. Он же — материал для показа пользователю перед вопросом «ок / идём дальше».

Все файлы — в scratchpad (`/tmp/claude-1000/.../scratchpad`), в проект не класть. Оригинал: `scratchpad/orig/shotNN.mp4` (план NN ≠ номер сцены: Scene1 = shot02, Scene7 = shot14). Моя запись: `SCENE=cutscene-sceneN ./shots.sh … <новый каталог> 31 12` (см. скилл edit-cutscene).

## Рецепты
1. **Лента сцены** (общий вид, N кадров по всей длительности; для оригинала и моего видео длительности разные — брать `fps=N/длительность`):
   `D=$(ffprobe -v error -show_entries format=duration -of csv=p=0 X.mp4); ffmpeg -loglevel error -y -i X.mp4 -vf "fps=4/$D,scale=400:225,tile=4x1" -frames:v 1 lenta.jpg`
   Две ленты друг под другом: `ffmpeg -y -i o.jpg -i m.jpg -filter_complex vstack both.jpg`.
2. **Пара в один момент** (оригинал t1 | моя запись t2; сдвиг времени подобрать по событию, например выстрелу): 
   `ffmpeg -ss T1 -i orig/shotNN.mp4 -frames:v 1 -vf scale=800:450 o.jpg; ffmpeg -ss T2 -i mine.mp4 -frames:v 1 -vf scale=800:450 m.jpg; ffmpeg -i o.jpg -i m.jpg -filter_complex hstack q.jpg`
   Несколько пар — `vstack=inputs=N`. Подпись: `-vf "scale=800:450,drawtext=text=mine 27.1:fontcolor=red:fontsize=24"`.
3. **Крупный план эффекта**: `-vf "crop=700:260:0:250"` до `scale`, чтобы разглядеть клубы/обломки.
4. **Показать пользователю**: Read картинки самому, а пользователю — `xdg-open <файл>` (`DISPLAY=:0 nohup xdg-open … &`) и полный абсолютный путь в ответе.

## Что смотреть в коллаже
Положение эффекта относительно борта/порта, размер относительно корабля, цвет (оранжевый огонь, белый дым), уровень воды у борта (до середины корпуса), ровность горизонта и амплитуду волн, яркость/дымку, что пропало или лишнее. Вывод формулировать конкретно («клубы ниже и мельче, взрыв сдвинут к краю»), затем править источник и повторять.

## Правила
- Каждый запуск записи — в **новый** каталог scratchpad (`rm` с glob блокируется).
- Длинные записи — с `timeout`, ошибки — по `error.log` (`grep -ci error`), его читать перед просмотром картинок.
- Не ставить значения «на глаз по одному кадру»: брать 3–4 момента (до, пик, после).
