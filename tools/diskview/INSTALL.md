# diskview: установка и запуск на другом ПК

diskview — один файл `diskview.py` на стандартной библиотеке Python. Сборки в «установщик» не требуется: достаточно скопировать файл и запустить. Ниже — три способа и перенос данных.

## 1. Требования

| Что | Зачем | Обязательно |
|---|---|---|
| Python 3.8+ (проверено на 3.10 и 3.14) | запуск | да |
| Браузер (Chrome, Edge, Firefox) | интерфейс на `http://127.0.0.1:8770` | да |
| Windows 10/11, Linux, macOS | Windows-функции: реестр установленных программ, иконки exe, корзина, запуск | диск, карта, библиотека работают везде |
| Ollama или OpenAI-совместимый сервер | описание папок, теги, помощник, авторазметка | нет, без модели остальное работает |
| Интернет | Steam, Википедия, DuckDuckGo для описаний и обложек | нет, есть режим «без интернета» (⚙ → Приватность) |

Сторонние пакеты Python (`pip install`) не нужны. Сервер слушает только `127.0.0.1`, порты в брандмауэре открывать не надо.

## 2. Установка Python

- **Windows:** https://www.python.org/downloads/ → при установке отметить «Add python.exe to PATH». Проверка: `python --version`.
  Через winget: `winget install Python.Python.3.12`.
- **Linux:** `sudo apt install python3` (обычно уже есть). Команда запуска — `python3`.
- **macOS:** `brew install python` или установщик с python.org.

## 3. Получить программу

Любой из вариантов:

- `git clone https://github.com/POMXARK/diskview` (репозиторий публичный или доступен вам);
- скачать `diskview.py` и `run.bat` из репозитория и положить в одну папку, например `C:\diskview`;
- скопировать папку флешкой или `scp diskview.py user@host:C:/diskview/`.

Нужны только `diskview.py` и (для Windows) `run.bat`.

## 4. Запуск

**Windows:** двойной клик по `run.bat`. Окно консоли остаётся открытым и показывает журнал сервера; браузер откроется сам. Закрыть программу — кнопка «⏻ Выход» на странице или Ctrl+C в консоли.

**Linux/macOS:**

```
python3 diskview.py
```

Параметры:

```
python diskview.py [--port 8770] [--no-browser]
```

- `--port` — другой порт, если 8770 занят (в консоли будет ошибка «address already in use»);
- `--no-browser` — не открывать браузер (удобно при перезапуске и на сервере).

Первый запуск: выберите диск или папку, нажмите «Сканировать». Следующие запуски показывают сохранённый скан сразу, повторное «Сканировать» обновляет только изменившиеся папки (галка «полностью» — заново).

## 5. Данные и перенос на другой ПК

Всё хранится в папке данных: `C:\Users\<имя>\.diskview` (Linux/macOS — `~/.diskview`). Свою папку можно задать переменной `DISKVIEW_DATA`.

| Файл | Что внутри |
|---|---|
| `library.json` | коллекции, теги, заметки, описания, статистика запусков |
| `cards.json` | сводки по папкам для помощника |
| `scan_*.json.gz`, `scan_last.json` | сохранённый результат сканирования |
| `analysis.json` | кэш ответов модели |
| `config.json` | профили модели и настройки приватности (может содержать ключ API) |
| `covers\` | загруженные вручную обложки и скриншоты |
| `diskview.log` | журнал сервера |

- Перенести библиотеку: скопировать `library.json` и `covers\` (и при желании `config.json`) в `.diskview` на новом ПК. Пути в коллекциях абсолютные, поэтому на другом ПК элементы с несуществующими путями будут помечены как отсутствующие; пересканирование и «↻ Пересканировать» их проверят.
- `config.json` с ключом API не публиковать и не отправлять в git.
- Чистая установка — просто не копировать папку данных.

## 6. Модель для ИИ-функций (по желанию)

1. Установить Ollama: https://ollama.com/download
2. `ollama pull qwen3:8b` (или `qwen3:4b`, если мало памяти).
3. В программе: «⚙ Модель» → профиль «Ollama (локально)», адрес `http://127.0.0.1:11434`, выбрать модель, «Проверить».

Подойдёт и любой OpenAI-совместимый сервер (LM Studio, llama.cpp, vLLM, OpenRouter): тип профиля, адрес, ключ, модель. В модель уходят только метаданные (названия, размеры, даты, теги), не содержимое файлов.

## 7. «Сборка» для запуска без Python

Способ A — один переносимый файл (нужен Python на целевом ПК). Работает без сторонних пакетов:

```
mkdir build
copy diskview.py build\__main__.py
python -m zipapp build -o diskview.pyz
python diskview.pyz
```

Файл `diskview.pyz` можно скопировать на другой ПК, где есть Python.

Способ B — exe без установленного Python (PyInstaller). Не проверялось на этом проекте; нужен интернет для установки PyInstaller на сборочной машине:

```
pip install pyinstaller
pyinstaller --onefile --name diskview diskview.py
```

Готовый `dist\diskview.exe` запускается двойным кликом. Антивирус иногда ругается на exe, собранные PyInstaller: добавьте в исключения или собирайте на машине, где запускаете.

## 8. Частые проблемы

- **`python` не найден** — Python не в PATH: переустановить с галкой «Add to PATH» или запускать `py diskview.py`.
- **«address already in use»** — уже запущена копия (закройте её кнопкой «⏻ Выход») или укажите другой `--port`.
- **Вкладки «Папки/Карта» пусты** — диск не просканирован: нажмите «Сканировать».
- **Нет иконок и списка программ** — эти функции только для Windows; на Linux/macOS остальное работает.
- **Модель не отвечает** — проверьте, что запущена Ollama и в «⚙ Модель» выбрана установленная модель; подробности в панели «📜 Логи» и в `diskview.log`.
- **Описания из Steam не находятся** — проверьте интернет и режим «без интернета» в «⚙ → Приватность».
- **Обновление** — заменить `diskview.py` новым, нажать «↻ Сервер» (или перезапустить) и обновить страницу Ctrl+F5. Данные сохраняются.
