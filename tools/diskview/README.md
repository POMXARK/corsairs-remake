# diskview — места на диске в стиле WizTree

`python tools/diskview/diskview.py` (на Windows — `run.bat`) открывает страницу `http://127.0.0.1:8770/`.
Только Python 3.8+, без установки пакетов. Ничего не удаляет.

- Выбор, что сканировать: кнопки дисков или любой путь; «файлы от N МБ» — какие файлы хранить в дереве поимённо (остальные идут в размер папки).
- «Папки»: дерево с размером, долей, числом файлов и датами создания / изменения / доступа (у папки — новейшие внутри).
- «Карта»: карта площадей, цвет по возрасту (зелёный — свежее, красный — старше 3 лет, по выбранной дате); двойной клик — войти в папку.
- «Старое»: самые внешние папки и файлы, которых не трогали дольше N лет и крупнее M МБ.
- «Показать в Проводнике» открывает выбранное, «Копировать путь» кладёт путь в буфер.
- Дата доступа пишется, если `fsutil behavior query disablelastaccess` даёт 0 или 2; антивирус и индексатор её обновляют, изменению доверять больше.
- Junction, симлинки и облачные заглушки пропускаются, чтобы не считать дважды.
