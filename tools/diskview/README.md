# diskview

Локальный просмотрщик диска в духе WizTree и помощник по данным. Один файл на стандартной библиотеке Python, страница в браузере (`127.0.0.1:8770`). Запуск: `run.bat` или `python diskview.py`.

- **Папки / Карта** — размеры, даты создания, изменения и доступа, выбор что сканировать, переход к файлу/папке.
- **Мёртвые папки** — большие и давно не менявшиеся, с оценкой риска; системные и пользовательские каталоги защищены.
- **Очистка** — в корзину или навсегда (подтверждение вводом имени). Сама ничего не удаляет.
- **Библиотека** — коллекции папок, теги «что и для чего», заметки; помощник отвечает по карточкам (BM25 + выбранная модель), ищет дубликаты (sha1 по выборке).
- **🤖 Авторазметка** (вкладка «Библиотека») — модель сама создаёт коллекции и теги: сначала смотрит существующие и использует их, новые добавляет только если ничего не подходит; по умолчанию сверяется с интернетом по именам папок. Созданное помечено 🤖; можно переименовать коллекцию/тег, править теги вручную (метка снимается) или откатить всё нажатием «Отменить авторазметку». Размеченное вами не трогается.
- **Лаунчер** — запуск программ и путей из коллекций и реестра Uninstall.
- **🖼 Картинки и описания** — для папок с тегом/коллекцией «игры» и «программы»: обложка, скриншоты, жанры и описание из Steam (наружу уходит только очищенное название; не нашлось — запоминается и повторно не ищется). Кнопка 🌐 на карточке делает то же для одной папки.
- **↻ Пересканировать** — пересчитывает размер, число файлов и даты изменения элементов коллекций (рост/убыль между сканами, пропавшие папки).
- **Использование** — открытия из лаунчера и «показать в Проводнике» считаются (всего, за 7/30 дней, последний раз); сортировка «чаще используются / давно не используются», фильтр 💤 «забытые» (нет открытий за 30 дней и ничего не менялось 90+ дней).
- Панель помощника в «Библиотеке» можно скрыть (💬 Помощник) и растянуть мышью; изменения карточек (теги, описание) сохраняются без перезагрузки списка.
- **🌐 В интернете** — для неизвестного exe/папки: поиск (Википедия, DuckDuckGo), описание, картинка и подсказки «что делать»; результат сохраняется в заметке. Наружу уходит только имя файла.
- **⚙ Модель** — любые профили: Ollama или OpenAI-совместимый сервер (LM Studio, llama.cpp, vLLM, OpenRouter, OpenAI…), адрес, ключ, модель, кнопка «Проверить». Рекомендуется `qwen3:8b`/`4b`. Конфиг — `~/.diskview/config.json`, ключ клиенту не отдаётся. Для внешних сервисов показывается предупреждение: уходят метаданные папок, не содержимое файлов.

Данные библиотеки — `~/.diskview` (или `$DISKVIEW_DATA`).

## Установка и запуск

Нужен только Python 3.8+ (без сторонних пакетов). Windows: `run.bat`; Linux/macOS: `python3 diskview.py`. Откроется `http://127.0.0.1:8770` (только локально).

```
python diskview.py [--port 8770] [--no-browser]
```

Для ИИ-функций (описание, теги, помощник) подключите модель в «⚙ Модель»: локальная Ollama (рекомендуется `qwen3:8b` или `4b`) или любой OpenAI-совместимый сервер. Без модели работают сканирование, карта, мёртвые папки, дубликаты, коллекции и ручные теги.

## Безопасность и приватность

- Сервер слушает только `127.0.0.1`.
- Очистка: в корзину или навсегда (подтверждение вводом имени); системные и пользовательские каталоги защищены; запуск возможен только для путей из библиотеки и списка установленных программ.
- В модель уходят только метаданные (названия, размеры, даты, типы, теги), не содержимое файлов. Для внешних сервисов показывается предупреждение.
- «🌐 В интернете» и «сверять с интернетом» отправляют в Википедию/DuckDuckGo только имя файла или папки и только по вашему действию.
