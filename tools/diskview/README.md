# diskview

Установка и сборка на другом ПК: [INSTALL.md](INSTALL.md).

Локальный просмотрщик диска в духе WizTree и помощник по данным. Один файл на стандартной библиотеке Python, страница в браузере (`127.0.0.1:8770`). Запуск: `run.bat` или `python diskview.py`.

- **Папки / Карта** — размеры, даты создания, изменения и доступа, выбор что сканировать, переход к файлу/папке.
- **Мёртвые папки** — большие и давно не менявшиеся, с оценкой риска; системные и пользовательские каталоги защищены.
- **Очистка** — в корзину или навсегда (подтверждение вводом имени). Сама ничего не удаляет.
- **Библиотека** — коллекции папок, теги «что и для чего», заметки; помощник отвечает по карточкам (BM25 + выбранная модель), ищет дубликаты (sha1 по выборке). Помощник учитывает описание и жанры из интернета (запрос «игры про пиратов» находит игры по описанию), прячет рассуждения модели, пути в ответе и источниках кликабельны (открывают Проводник). В строке помощника — подсказки как в поиске Google: названия, теги, жанры, слова из описаний и шаблоны запросов (↑↓, Tab, Enter, Esc). Авторазметка обновляет карточки, коллекции и теги по ходу работы; в ответе помощника клик по источнику переводит фокус на карточку, а «🎯 Показать в карточках» оставляет в списке только найденное (чип «🎯 из помощника ✕» снимает фильтр). Кнопка ▶ на карточке запускает главный exe папки (файл запуска можно задать в ✎); «📜 Логи» показывает, что делает сервер (то же печатается в консоли); фоновый поиск в Steam на время авторазметки приостанавливается и потом продолжается. «Что это? (ИИ)» показывает рассуждения модели и полный вывод в прокручиваемой панели; ответы «Что это?» и «Теги ИИ» кэшируются (analysis.json) и пересчитываются, только если папка изменилась больше чем на 3% или нажато «↻ Пересчитать». Результат сканирования сохраняется на диск (scan_*.json.gz) и восстанавливается после перезапуска сервера; повторное «Сканировать» перечитывает только папки с изменившимся временем (галка «полностью» — всё заново). Файлы, изменённые на месте без смены времени папки, видны после полного скана.
- **🤖 Авторазметка** (вкладка «Библиотека») — модель сама создаёт коллекции и теги: сначала смотрит существующие и использует их, новые добавляет только если ничего не подходит; по умолчанию сверяется с интернетом по именам папок. Созданное помечено 🤖; можно переименовать коллекцию/тег, править теги вручную (метка снимается) или откатить всё нажатием «Отменить авторазметку». Размеченное вами не трогается.
- **Лаунчер** — запуск программ и путей из коллекций и реестра Uninstall.
- **Группировка в Лаунчере**: вложенные папки игры (Content, Paks, runtime…) и копии одной игры (одно название в Steam) собираются в одну карточку; «＋ ещё N» раскрывает список с размерами и кнопкой 📂, в пилюле сумма Σ без двойного учёта.
- **Поиск описания, если полное имя не нашлось**: по формулировкам покороче и с поправкой на опечатки, затем по названиям раздач на торрент-трекерах (наружу уходит только название), затем снова Steam; если ничего — предлагается ввести название вручную.
- Скриншоты открываются поверх страницы (← → Esc).
- **Ручное редактирование карточки** (✎): название, описание, жанры, теги, обложка и скриншоты — ссылкой или файлом (сохраняется в `~/.diskview/covers`). Введённое вручную помечено «вручную»; кнопка 🌐 спросит, заменять ли его найденным.
- **Лаунчер и Библиотека**: Лаунчер — плоская галерея всех элементов (клик запускает, сортировка по использованию); Библиотека — те же карточки, но по коллекциям, с ИИ-помощником. Группировка и редактор работают в обеих. Одна игра или папка в нескольких коллекциях (и копии вида «Name_») показывается одной карточкой «＋ ещё N» с пометкой коллекции; общие имена подпапок (models, Data, target…) сравниваются вместе с родителем. Выпадающий список коллекций внизу — одновременно фильтр Лаунчера и Библиотеки («Все коллекции» — без фильтра) и цель кнопки «В коллекцию». Кнопка «⏻ Выход» справа в меню останавливает сервер. Описание на карточке обрезано тремя строками — клик разворачивает, в подсказке полный текст. Кнопки «⟳ Страница» и «↻ Сервер» в меню: перезагрузка страницы и перезапуск сервера (подхватывает обновлённый diskview.py) с автообновлением страницы. ⚙ → «Приватность поиска»: режим «без интернета», запрещённые теги/коллекции/папки и автофильтр по взрослым словам — для таких папок ни автопоиск, ни 🔍 ничего не отправляют.
- **Карточки как в менеджере модов**: крупная обложка, скриншоты, настоящая иконка игры/программы (256 px из её главного exe, подпапки вроде Content/Paks берут иконку и имя родителя), размер, жанры, теги; кнопки появляются при наведении. Обложки и описания подтягиваются сами при открытии «Библиотеки».
- **🖼 Картинки и описания** — для папок с тегом/коллекцией «игры» и «программы»: обложка, скриншоты, жанры и описание из Steam (наружу уходит только очищенное название; не нашлось — запоминается и повторно не ищется). Кнопка 🔍 на карточке делает то же для одной папки, 🌐 открывает страницу в браузере (Steam или поиск Google).
- **↻ Пересканировать** — пересчитывает размер, число файлов и даты изменения элементов коллекций (рост/убыль между сканами, пропавшие папки).
- **Использование** — открытия из лаунчера и «показать в Проводнике» считаются (всего, за 7/30 дней, последний раз); сортировка «чаще используются / давно не используются», фильтр 💤 «забытые» (нет открытий за 30 дней и ничего не менялось 90+ дней).
- Панель помощника в «Библиотеке» можно скрыть (💬 Помощник) и растянуть мышью; изменения карточек (теги, описание) сохраняются без перезагрузки списка.
- **🌐 В интернете** — для неизвестного exe/папки: поиск (Википедия, DuckDuckGo), описание, картинка и подсказки «что делать»; результат сохраняется в заметке. Наружу уходит только имя файла.
- **⚙ Модель** — любые профили: Ollama или OpenAI-совместимый сервер (LM Studio, llama.cpp, vLLM, OpenRouter, OpenAI…), адрес, ключ, модель, кнопка «Проверить». Рекомендуется `qwen3:8b`/`4b`. Конфиг — `~/.diskview/config.json`, ключ клиенту не отдаётся. Для внешних сервисов показывается предупреждение: уходят метаданные папок, не содержимое файлов.

Данные библиотеки — `~/.diskview` (или `$DISKVIEW_DATA`).

## Установка и запуск

Нужен только Python 3.8+ (без сторонних пакетов). Windows: `run.bat`; Linux/macOS: `python3 diskview.py`. Откроется `http://127.0.0.1:8770` (только локально).

```
python diskview.py [--port 8770] [--no-browser]
```

Для ИИ-функций (описание, теги, помощник) подключите модель в «⚙ Модель»: локальная Ollama (рекомендуется `qwen3:8b` или `4b`) или любой OpenAI-совместимый сервер. Без модели работают сканирование, карта, мёртвые папки, дубликаты, коллекции и ручные теги.

## Безопасность и приватность

- Сервер слушает только `127.0.0.1`.
- Очистка: в корзину или навсегда (подтверждение вводом имени); системные и пользовательские каталоги защищены; запуск возможен только для путей из библиотеки и списка установленных программ.
- В модель уходят только метаданные (названия, размеры, даты, типы, теги), не содержимое файлов. Для внешних сервисов показывается предупреждение.
- «🌐 В интернете» и «сверять с интернетом» отправляют в Википедию/DuckDuckGo только имя файла или папки и только по вашему действию.
