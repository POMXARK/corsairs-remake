# diskview

Локальный просмотрщик диска в духе WizTree и помощник по данным. Один файл на стандартной библиотеке Python, страница в браузере (`127.0.0.1:8770`). Запуск: `run.bat` или `python diskview.py`.

- **Папки / Карта** — размеры, даты создания, изменения и доступа, выбор что сканировать, переход к файлу/папке.
- **Мёртвые папки** — большие и давно не менявшиеся, с оценкой риска; системные и пользовательские каталоги защищены.
- **Очистка** — в корзину или навсегда (подтверждение вводом имени). Сама ничего не удаляет.
- **Библиотека** — коллекции папок, теги «что и для чего», заметки; помощник отвечает по карточкам (BM25 + выбранная модель), ищет дубликаты (sha1 по выборке).
- **🤖 Авторазметка** (вкладка «Библиотека») — модель сама создаёт коллекции и теги: сначала смотрит существующие и использует их, новые добавляет только если ничего не подходит; по умолчанию сверяется с интернетом по именам папок. Созданное помечено 🤖; можно переименовать коллекцию/тег, править теги вручную (метка снимается) или откатить всё нажатием «Отменить авторазметку». Размеченное вами не трогается.
- **Лаунчер** — запуск программ и путей из коллекций и реестра Uninstall.
- **🌐 В интернете** — для неизвестного exe/папки: поиск (Википедия, DuckDuckGo), описание, картинка и подсказки «что делать»; результат сохраняется в заметке. Наружу уходит только имя файла.
- **⚙ Модель** — любые профили: Ollama или OpenAI-совместимый сервер (LM Studio, llama.cpp, vLLM, OpenRouter, OpenAI…), адрес, ключ, модель, кнопка «Проверить». Рекомендуется `qwen3:8b`/`4b`. Конфиг — `~/.diskview/config.json`, ключ клиенту не отдаётся. Для внешних сервисов показывается предупреждение: уходят метаданные папок, не содержимое файлов.

Данные библиотеки — `~/.diskview` (или `$DISKVIEW_DATA`).
