# Чего не хватает в ремейке по сравнению с оригиналом (план)

Сравнение по экранам: скриншот оригинала (Windows, PDM 1.061) и ремейка на одной странице. Порядок: что можно получить конвертером из данных оригинала, затем код скриптов, затем то, что требует рендера или нового движка. Статусы: ☐ не начато, ◐ в работе, ◐ сделано.

## 1. Экран «Верфь» (shipyard)

Ремейк показывает только цифры из карточки корабля героя; у оригинала заполнено всё.

| # | Чего нет | Откуда взять | Как | Статус |
|---|---|---|---|---|
| 1.1 | Название типа корабля в плашке («Пинк») | `TEXTS/RUSSIAN/GOODS/SHIPS/<файл>.nme` | конвертер `pdm_ui.py`: `names("ships")`; в скрипте `EDITSHIPTYPE` (раньше писали в несуществующий `EDITSHIPTYPENAME`) | ◐ |
| 1.2 | Описание корабля внизу | `.../SHIPS/<файл>.txt` | то же, узел `EDITDESC` | ◐ |
| 1.3 | «Борт 4 + 4», «Корма 1» | `deckcannons`, `cannonback` типа | скрипт: `S_BOARD`, `S_STERN` (было `S_BOARDNUM`) | ◐ |
| 1.4 | Текущий калибр, вес ядра, дальнобойность, перезарядка, название орудия | `PdmCannons` (`params`, `reloadtime`, `weight`) | скрипт | ◐ |
| 1.5 | Состояние корпуса и оснастки (`100%`), стоимость ремонта, «Урона на 0» | карточка корабля героя | скрипт | ◐ |
| 1.6 | «Цена корабля N», «Деньги N» | `sellprice`/`buyprice`, деньги героя | скрипт | ◐ |
| 1.7 | Фраза про ранг («Ваш ранг позволяет управлять вам кораблями до 6 класса») | текст `ShipYardrank` из `menu.ini`/`TEXTS` | конвертер + скрипт; правило ранга и фильтр списка перенесены (`Screen_RankClass`, `Screen_YardHas`, тест shipyard-screen) | ◐ |
| 1.8 | Список кораблей по классам справа, «Ваш корабль» | типы `PdmShipTypes` с названиями | скрипт | ◐ |
| 1.9 | Картинка корабля в рамке | оригинал рисует 3D-модель `MODELS/<файл>.cff` | картинки оригинала `IMAGES/GOODS/SHIPS/<id>_lg.tga` конвертером `pdm_ui.py` (ship_<id>.tga.tx), узел `SHIPSPRITE`; проверено кадром (пинк) | ◐ |
| 1.10 | Картинка орудия | `IMAGES/GOODS/GOODS/<файл>64.tga` | `pdm_ui.py` (cannon_<файл>.tga.tx), узел `CANNONSPRITE`; проверено кадром | ◐ |
| 1.11 | Кнопки «Продать/Полностью/Починить/Замена/Обшить корпус» работают | логика `TOWN.dll` (SHIPYARD) | покупка/продажа/ремонт в скрипте | ◐ продать, купить, листание типов; «Починить» и «Полностью» — с нашей ценой (формулы оригинала нет), стрелки ±10% работают; «Обшить корпус» — в оригинале не работает, кнопка скрыта (решено) |
| 1.12 | Шрифты: у оригинала один без засечек, у ремейка засечки; кнопка «Выход» мельче | `fonts.ini` оригинала называет `seawolf`, `log-russ`, `Interface`: это системные TTF Windows, в папке игры их нет, взять из оригинала нельзя | заменители со свободной лицензией (PT Serif, Old Standard) — наше, не оригинал; нужны файлы этих шрифтов | ☐ |

## 2. Остальные экраны с тем же дефектом (проверить по очереди)

Для каждого экрана: снимок оригинала и ремейка рядом, список пустых узлов (`grep` узлов `.ini` без значения в `Screen_Value`), исправление конвертером либо кодом.

| Экран | Что проверить | Статус |
|---|---|---|
| `trade` (магазин) | склад, цены, экспорт/импорт, количество, вес и деньги — по `TOWN.dll`; нет: множитель цены острова, игровой даты, поля героя `+0x3d8`, смены корабля | ☑ (кадр, `screens`) |
| `sship`, `sgoods`, `schest` | значения корабля, груза, сундука | ◐ (кадры и тест `status-screens`; описание корабля в своём узле, единицы без повтора, износ корпуса и оснастки в %; не сделаны строки ремонта, не проверен сундук; первая строка описания у кромки пергамента — позиция узла из .ini) |
| `crew`, `tavern` | в оригинале не открываются (остатки `town.ini`), тест не нужен | ✖ |
| `shipexchange`, `transfer` | обмен кораблями, передача груза | ◐ (страницы открываются, тест `ransack-screens`; слева данные корабля героя, справа значения призового корабля (тип, класс, корпус, скорость, экипаж, трюм, орудия — узлы `S_*1`, конвертер `second_ship`, тип запоминает `Board_Prize`; в тесте подставлен «Пинас», маркер `PDM prize: right Pinnace,4`), кнопка «Взять призовой корабль» работает (те же правила экипажа и ранга, приз берётся один раз, при отказе остаётся предложенным; тест `prize-button`), трюм приза пуст, нет кнопки «Сменить», передачи товаров) |
| `logbook` | журнал: записи квестов на страницах, «Дальше/Назад», подписи наций (все «Нейтрально», наше); нет деления по пикселям, дат, списка квестов | ◐ |
| `mainmap` | карта мира; встречи с кораблями — `encounter.c` (есть: порог, паттерны, окно, бой: первый корабль + эскорт отряда (до 3, наше: бой до гибели всего отряда, TOWN_AUTO=26; абордаж только первого); наше: торговец после «Напасть» убегает (AITASK_RUNAWAY), тест TOWN_AUTO=25; дата и часы, якорь с шестью вариантами — проверено кадром (TOWN_AUTO=27); сообщения 6 (плата команде) и 7 («якорь брошен») и 8 («земля») — по логу тестов, кадра нет; уход от погони с моря на карту (враг ближе 600 м — отказ, порог «наш», тест sea-escape); курсор карты и прокрутка у краёв окна (тест map-scroll, кадр курсора у левого края); нет: Shift/ЛКМ-ускорение прокрутки, ползунок списка, войны наций, шторм (5), звуки yakor/mapisland) | ◐ |

## 3. Как проверять

- Кадр экрана ремейка: `pdm-game/shots.sh` (сценарий `screens`) и сравнение с кадром оригинала, который даёт пользователь (папка `docs/media/`).
- Тест на экран: автотест листает экран и пишет в `compile.log` значения узлов; маркер вида `PDM shipyard: values ok` (описывается в `docs/autotests.md`).

Проверка кадром (скриншот ремейка, `/tmp/…/town-38.jpg`) после первой правки: название типа, описание, список по классам, цена, 100% видны. Картинка корабля (1.9) видна на кадре. Картинка орудия (1.10) видна. Ещё нет: «Деньги N» (1.13: узел `EDITFACEMONEY` стоит в ini слева внизу, у оригинала справа внизу), список «Класс 5/6» берёт все типы, а не только доступные по рангу, кнопка «Обшить корпус» налезает на описание (у оригинала скрыта), шрифты мельче, значения скорости/маневренности `9.0`/`55.0`, «Доступные калибры» пусто (строки `S_LBS*`/`S_GOLD*` пусты и у оригинала в этом режиме — `Screen_ShipyardHide`; заполняются только в режиме замены орудий, которого у нас нет).

Тест верфи: сценарий `shipyard-screen` (`docs/autotests.md`): город → верфь → диалог с Бишопом → ответ «верфь» → экран; проверяет значения в скрипте, не отрисовку — отрисовку смотреть кадром.
