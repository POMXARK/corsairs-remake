# Промпт для продолжения работы на Windows

Вставьте текст ниже первым сообщением в Claude Code (или другого агента), открытого в папке `corsairs-remake` на Windows 11 + RTX 5080.

---

Ты продолжаешь порт «Корсаров» (Акелла, PDM 1.061) на открытый Storm Engine. Общайся по-русски и работай автономно: сначала читаешь код, потом сразу делаешь изменения.

**Где что.**
- `corsairs-remake/` — игра.
- `corsairs-remake/engine/` — движок (форк storm-engine, ветка `pdm-launch`). Архив собран без `.git`, поэтому изменения после распаковки отслеживай сам (`git init` + первый коммит «snapshot» — удобно).
- Оригинал игры (установленная PDM 1.061 с папкой `RESOURCE`) лежит отдельно. Путь задаётся в `pdm-game/local.ps1`: сохранять в UTF-8 с BOM, иначе кириллица в пути ломается.
- Документы: `docs/README.md`. Сборка и запуск на Windows описаны в `docs/build.md`, раздел «Windows».

**Сборка и запуск.**
- Движок: `build.bat` в корне (ставит Conan, CMake, Ninja, Pillow и numpy). Результат — `engine/build/default/Debug/engine.exe`.
- Игра: `pdm-game\game.bat`, без аргументов показывает меню. При первом запуске `run.ps1` конвертирует оригинал в `pdm-game/resource`, `data`, `program/data`.
- Логи: `%USERPROFILE%\Documents\My Games\Sea Dogs\Logs\` или рядом, в `Akella\Sea Dogs\Logs`: `error.log`, `system.log`, `compile.log`.
- Сцены: `SCENE=menu|town|sea|screens|story`, `TOWN=City_HighRock`, `TOWN_AUTO=1..5` (автотесты без нажатий). Список — в шапке `pdm-game/run.sh` и в `docs/test-commands.md`.

**Правила.**
- Только свободные ассеты.
- Данные оригинала и всё, что из них сконвертировано, в git не класть (уже в `.gitignore`).
- Тесты — через `PostEvent` в скриптах, не эмуляцией клавиш.
- Конвертеры идемпотентны: два прогона дают один md5.
- Свои решения помечать в комментариях «ours».
- Коммиты на английском, стиль: `feat:`/`fix:`/`chore:`, строки `- файл — что — почему`, блок `Tests:`.
- Не коммитить и не пушить, пока пользователь не попросит.

**Сделано, но не закоммичено (в архиве — рабочее состояние):**
1. **Escape в игре** открывает главное меню поверх игры, а не закрывает программу (`pdm-game/program/screens.c`: `Screen_GameMenu`, `screenGameMenu`; `main.c`: `Pdm_Control`).
   - «Продолжить» и Escape возвращают в игру; «Настройки» возвращаются в это меню.
   - «Выход» спрашивает подтверждение. «Новая игра» поверх игры отключена.
   - Проверено в `SCENE=town`, `error.log` пуст.
   - Недоделка: курсор меню стоит на неактивной «Новой игре», лучше поставить его на «Продолжить».
2. **Нейрогенерация 3D-моделей через ComfyUI** (`docs/ai-models.md`):
   - `tools/pdm_model_views.py` — 4 вида модели;
   - `tools/comfy_model_batch.py` — пакетный прогон через API ComfyUI;
   - `tools/pdm_glb2gm.py` — GLB → `.gm` с переносом костей, `--restore`.
   - Конвертер проверен на тестовом GLB. С ComfyUI ещё не запускалось: нужен шаблон «Pixal3D: Multi Views to 3D» (MIT), экспортированный как API в `tools/model3d/image_to_model_api.json`, с узлами `IMAGE`, `IMAGE_RIGHT`, `IMAGE_BACK`, `IMAGE_LEFT`, `SEED`, `FACES`, `SAVE`.
   - Hunyuan3D не брать: лицензия не действует в ЕС.
3. **Нейроозвучка реплик** (`docs/voice-over.md`, `tools/pdm_voice_*.py`, `tools/comfy_voice_batch.py`; в движке `src/libs/dialog` — голос реплики).
   - Поворот головы — только естественный (`animation_imp.cpp`).
   - Не сделано: прогнать `SCENE=town TOWN_AUTO=2` со звуком, удалить тестовые тоны падре Игнасио, выполнить `pdm_voice_lines.py pdm-game --bind`.
4. **Невидимые стены на улицах** (`tools/pdm_world.py`, `docs/original-vs-remake.md`). Большая часть убрана. Проверка: `python tools/ptc_seams.py <RESOURCE> City_HighRock ...` печатает швы, длинные — первыми; короткие не важны.

**Следующая задача — оставшиеся длинные швы пола:**

| Город | Длина | Где (x, z) |
|---|---|---|
| City_HighRock | 6,9 м | (17,5; −15,5) |
| City_IsleDOrange | 6 м | (13,8; 3,4) |
| City_IsleDOrange | 2 м | (11,0; −6,3) |
| City_Tendales | 6 м | (−6,9; 29,8) |
| City_SharkIsland | 3 м | (−15,5; 11,1) |

Причины найдены, в `clean_patch` (`tools/pdm_world.py`):
- **Tendales, IsleDOrange, SharkIsland.** Края двух соседних кусков пола почти совпадают, но расходятся на 2–3 мм. `on_edge` вставляет вершину соседа в ребро только при расстоянии до 1 мм (`>= 1.0`), поэтому рёбра остаются несшитыми.
- **HighRock.** Три вершины в 1–2 см друг от друга дают узкие клинья длиной 6,9 м на одном ребре. Блок `walled` поднимает вершины клина, и открываются оба длинных ребра.

Глобальные допуски не помогают, проверено:
- допуск `on_edge` 4 мм и `MERGE` 10–30 убирают одни швы и создают другие (Tendales 12,8 м, grot 11 м);
- эксперимент «ear_clip вместо веера + drop_covered» ухудшает Granda Avilia.

План: отдельный проход `stitch(out)` перед блоком `walled`, только по **открытым** рёбрам.
1. Концы открытых рёбер ближе 1 см и с разницей высот меньше 5 см сливаются.
2. Конец, лежащий ближе 5 мм от чужого открытого ребра, делит его треугольник на два (проверять, что площади положительные).
3. Повторять до 50 раз, пока что-то меняется.

В блоке `walled` клин, который делит ребро с треугольником **той же** стороны и тоньше 2 см, лучше удалять, а не поднимать.

Проверка:
- `ptc_seams.py` на `City_GrandaAvilia City_HighRock City_IsleDOrange City_SharkIsland City_Tendales grot tavern_spa` — нет новых швов длиннее 1,5 м;
- `pdm_world.py` дважды — один md5 у всех `.ptc`;
- `SCENE=town TOWN=<город>` — герой проходит по месту бывшего шва.
