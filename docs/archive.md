# Сборка из архива

«Корсары» (PDM 1.061) на открытом Storm Engine: скрипты игры, конвертеры и исходники движка в одном архиве. Git не нужен, движок уже лежит в `engine\`. Файлов оригинала в архиве нет: они берутся из вашей установленной игры и конвертируются при первом запуске.

## Что нужно

1. **Windows 10/11, x64.**
2. **Visual Studio 2022** (или Build Tools 2022/2019) с нагрузкой «Разработка классических приложений на C++».
3. **Python 3.9+** с python.org, при установке отметить «Add to PATH».
4. **Интернет при первой сборке.** Скрипт сам ставит через pip Conan, CMake, Ninja, Pillow и numpy, а Conan скачивает библиотеки движка (zlib, SDL, spdlog и др.) и собирает их. Это 15–30 минут, потом всё берётся из кэша.
5. **Установленные «Корсары» 1.061** (Акелла / 1С, 2000), русская версия с патчем 1.061: папка с `RESOURCE\`, `MODULES\` и `ENGINE.INI`.
6. **DirectX End-User Runtime (June 2010)** — если при запуске не хватает `d3dx9_43.dll`.

## Шаги

1. Распакуйте архив, например в `C:\corsairs-remake`. Путь лучше без пробелов и кириллицы.
2. Укажите путь к оригиналу: создайте `pdm-game\local.ps1` с одной строкой:
   ```powershell
   $env:PDM = 'C:\Program Files\1C\Корсары'
   ```
   Если в пути есть кириллица, сохраните файл в **UTF-8 с BOM** (в Блокноте: «Сохранить как» → кодировка «UTF-8 с BOM»), иначе Windows PowerShell прочитает путь неверно. Можно обойтись без файла: по умолчанию игра ищется в папке `Корсары` рядом с распакованной (`C:\Корсары`).
3. Запустите `pdm-game\game.bat` двойным щелчком и выберите `1` или в PowerShell:
   ```powershell
   cd C:\corsairs-remake\pdm-game
   .\game.bat run Debug menu
   ```
   Первый запуск собирает движок (`engine\build\default\Debug\engine.exe`), затем конвертирует оригинал в `pdm-game\resource`, `data` и `program\data` (10–15 минут), затем открывает главное меню. Следующие запуски сразу открывают игру.

## Команды

| Команда | Что делает |
|---|---|
| `game.bat` | меню со всеми действиями |
| `game.bat build Debug` / `build Release` | только собрать движок |
| `game.bat run Debug menu` | играть; вместо `menu` — `town`, `sea`, `battle`, `review`, `quest`, `story` |
| `game.bat convert` | сконвертировать оригинал заново |
| `game.bat check` | проверить окружение: путь к оригиналу, движок, Python, CMake, Conan |
| `game.bat logs` | хвост логов |
| `game.bat keys` | управление |
| `game.bat package` | Release-сборка с данными в `dist\` — только для себя, в ней данные оригинала |

## Если что-то не так

- **Логи** — `Документы\My Games\Sea Dogs\Logs\`: `error.log` (должен быть пустым), `system.log`, `compile.log`.
- **Сборка упала** — вывод окна и `engine\build\default\CMakeFiles\CMakeConfigureLog.yaml`. Частая причина — нет C++ в Visual Studio или нет сети при первом скачивании библиотек.
- **«no original at …»** — неверный `$env:PDM` в `local.ps1`.
- **Повторная сборка с нуля** — удалить `engine\build`.

Подробно о шагах конвертации и управлении — `docs\build.md`. Что сделано и что нет — `docs\port-plan.md`.
