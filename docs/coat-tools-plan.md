# План: инструменты 3DCoat без 3DCoat

Цель — иметь открытые копии инструментов 3DCoat, которые нужны для правки моделей, и применять их к любой модели на Linux. Что уже сделано и как измерено — в `docs/coat-tools.md`.

Как работаем: 3DCoat изучаем как чёрный ящик — подаём сетки через Python API и смотрим результат. Дизассемблировать нельзя по EULA, п. 4.1. Ghidra остаётся только для оригинальной игры.

Цикл каждого пункта:
1. Тестовые сетки — `coat_probe.py make`.
2. Прогон в 3DCoat — `coat_probe.py run`. 3DCoat запускается свёрнутым, `MIN=1`.
3. Сравнение с открытым алгоритмом — `coat_probe.py analyze`.
4. Копия в `coat_algos.py` и её проверка — `verify`.
5. Запись в `docs/coat-tools.md`, коммит.

## Дальше, по порядку

### 1. Свёрнутый запуск для UV-режимов
- **Зачем:** UV-режимы (`auto`, `export`) переключают комнаты и закрывают диалоги, и свёрнутое окно может это сорвать.
- **Шаги:** прогнать `coat_run.sh fix2/solid.obj out.obj auto` с `MIN=1`, сравнить с прежним `solid_auv.obj`: число островов и uv_score.
- **Готово, когда:** результат тот же. Если зависает — в `coat_run.sh` для UV-режимов ставить `MIN=0`.

### 2. Правило Auto Seams
- **Зачем:** разрезы без 3DCoat на любой модели и без осколков.
- **Сетки:**
  - куб с фасками 10°, 20°, 30°, 45°, 60° — порог угла;
  - цилиндр и тор — где режет замкнутые трубки;
  - шумная сфера — откуда берутся осколки;
  - сетка головы на 5 и 20 тыс. граней — зависит ли от плотности.
- **Нужно:** добавить в `coat_autouv.probe` операцию `autoseams`: импорт, `$AutoEdges`, запись разрезов через `coat.uv.getSeams`.
- **Готово, когда:** найдены порог угла и правило для осколков; `coat_algos.autoseams` повторяет разрезы 3DCoat (доля совпадающих рёбер > 90 %).

### 3. ABF (метод 2)
- **Зачем:** развёртка с углами как у LSCM, но с меньшим растяжением площади.
- **Шаги:** сравнить выход 3DCoat с ABF++ (Sheffer и др., 2005) по статье. Взять готовую свободную реализацию, если найдётся (лицензия MIT/BSD), иначе написать на scipy.
- **Готово, когда:** остаток < 0,02 на тестовых сетках.

### 4. Упаковка `uv.pack`
- **Зачем:** у нас упаковывает xatlas, и он хуже 3DCoat. На hero1 заполнение 0,60 против 0,69, uv_score 2,4 против 3,97.
- **Шаги:**
  1. Добавить в `coat_autouv` режим `pack`: импорт obj с готовой UV, `coat.uv.pack(0, rotate, shuffle)`, `$ApplyUV`, запись.
  2. Измерить на наборе прямоугольников и на атласе `uv_unfold`: повороты (90° или любые), отступы, порядок по площади, масштаб островов.
- **Готово, когда:**
  - `uv_unfold.py` может упаковать через 3DCoat (свёрнутым);
  - открытая упаковка (`coat_algos.pack` или настройки xatlas) по заполнению не хуже 3DCoat на 0,03.

### 5. Развёртка полос (метод 4)
- **Зачем:** пряди, ремни, канаты — длинные куски без искажения.
- **Шаги:** сетки-полосы (прямая, изогнутая, скрученная) и выход 3DCoat; копия — развёртка вдоль средней линии.
- **Готово, когда:** остаток < 0,02.

### 6. Объёмные инструменты
`Volume.relaxSurface`, `relaxVoxels`, `closeHoles`, `fromVolumeWithMaxPolycount`.
- **Шаги:** шар и куб с дыркой известного размера. Измерить:
  - сдвиг поверхности от степени;
  - какие дыры закрываются, по размеру;
  - число граней и их равномерность после ремеша.
- **Копии:** через открытые библиотеки (voxel → marching cubes в scikit-image, сглаживание, закрытие дыр морфологией).
- **Готово, когда:** открытая копия даёт ту же форму, расстояние Хаусдорфа < 1 % размера.

### 7. `reduceToPolycount` и `weld`
- **Шаги:** сравнить с quadric decimation (open3d / pymeshlab) по ошибке формы и сохранению краёв UV; `weld` — по расстоянию слияния.
- **Готово, когда:** известно, чем заменять и с какими параметрами.

### 8. Применение к другим моделям
- **Шаги:** прогнать конвейер на второй модели (другая голова или предмет) только открытыми копиями: части → разрезы → развёртка → упаковка → проекция видов. Сравнить с вариантом через 3DCoat по `uv_score` и `head_check`.
- **Готово, когда:**
  - открытый вариант не хуже на 10 %;
  - рецепт записан в `docs/head-model-fix.md` и в скилл `head-model-fix`.

## Тупики (не повторять)
- **LSCM на сложенных дырявых островах** не совпадает с 3DCoat. Выбор закреплённых вершин этого не объясняет; прямое решение и lsqr дают один и тот же ответ.
- **ARAP вместо проекции** не убирает наложение у островов, свёрнутых в 3D: нужны разрезы.
- **ARAP в `uv_unfold`** хуже LSCM: uv_score 2,06 против 2,40.
- **3DCoat совсем без окна** (из ssh без рабочего стола) не работает: нужен рабочий стол пользователя, поэтому запуск идёт через задачу `coatrun` с `/it`.
