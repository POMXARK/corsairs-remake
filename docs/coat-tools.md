# Как устроены инструменты 3DCoat и как применять их без 3DCoat

Здесь описано, что делают инструменты 3DCoat из конвейера головы (docs/head-model-fix.md): сглаживание, развёртка острова, авто-разрезы. Для каждого есть измеренная формула и открытая копия в `tools/model3d/coat_algos.py`. С ней тот же результат получается на Linux для любой модели, без Windows и 3DCoat.

## Как это выяснено (чёрный ящик)

Лицензия 3DCoat (EULA, п. 4.1) запрещает дизассемблировать программу. Поэтому её код не декомпилировался. Исследование шло только через публичный Python API (`coat.pyi`):

1. `coat_probe.py make dir [auto_uv.obj]` строит тестовые сетки с известной геометрией:
   - полуцилиндр — развёртывается без искажений, любой хороший метод даёт точный ответ;
   - сферическая шапка 60°;
   - седло с очень неравными треугольниками — LSCM зависит от формы треугольников, угловые методы меньше;
   - три самых больших острова настоящей головы из Auto Seams;
   - шумная сфера (икосфера 3, шум 4 % радиуса);
   - шумный куб (3 подразбиения, шум 0,02) — для сглаживания и рёбер.
2. `coat_probe.py run dir` передаёт сетки на Windows. Там 3DCoat (`coat_autouv.py`, режим `probe`) применяет к каждой сетке по одному инструменту и пишет результат:
   - `flattenSingleIsland` с методами 0–4;
   - `Mesh.relax` со степенями 0,1 / 0,3 / 0,5 / 1 / 2 / 5, с `tangent` и без, плюс `crease`.
3. `coat_probe.py analyze dir` сравнивает каждый выход с открытыми алгоритмами и подбирает их параметры. Метрики:
   - остаток подобия: RMS после лучшего сдвига, поворота, масштаба и зеркала, в долях размера;
   - искажение углов: среднее |log σ1/σ2|;
   - искажение площадей: среднее |log площадь UV / площадь 3D|.

   3DCoat перенумеровывает вершины и грани, поэтому грани сопоставляются распространением от совпавшей пары (`match_faces`).
4. `coat_algos.py verify dir` проверяет копии на тех же данных.

3DCoat запускается свёрнутым (`coat_run.sh`, `MIN=1`). Список probe1 (37 задач) проходит примерно за 2 минуты, probe2 (48 задач) — за 179 с.

## Mesh.relax — сглаживание (копия точная)

**Что делает.** Каждая вершина сдвигается к среднему своих соседей по рёбрам (равномерный «зонтичный» лапласиан, без весов по углам): `p ← p + λ·(среднее соседей − p)`.

**Степень `degree`:**
- при `degree ≤ 1` — один шаг с λ = degree;
- при `degree > 1` — n = ⌊degree⌋ + 1 шагов с λ = degree / n. Например, 2 → 3 шага по 0,667, 5 → 6 шагов по 0,833.

**`tangent`.** Из шага убирается его часть вдоль нормали вершины. Нормаль взвешена площадями граней и пересчитывается по текущей сетке на каждом шаге. Поверхность не усаживается, выравниваются только расстояния между вершинами.

**`crease` (градусы).** Вершины рёбер, у которых грани сходятся под углом больше crease, не двигаются: углы куба остаются.

**Точность.** Остаток против 3DCoat — не больше 0,000001 на всех 25 случаях (сфера и куб, все степени, tangent 0/1, crease 30).

**Как применять:**
- `coat_algos.py relax in.obj out.obj 1.0 [tangent] [crease]`;
- в правке головы — инструмент `open_relax` (`head_tools.py … --region eyes~2 open_relax degree=1`). Он двигает только вершины внутри области. На глазах hero1 он даёт 91 вершину, доля складок 0,15 → 0,08.

**Чем отличается от `relax` в head_tools.** Тот использует фильтр Taubin: шаг вперёд и шаг назад, поэтому без усадки. Равномерный лапласиан 3DCoat без `tangent` при больших степенях сжимает выпуклые места (нос, уши). Для формы лучше `tangent=1` или Taubin.

## uv.flattenSingleIsland — развёртка одного острова

| Метод | Что это | Открытая копия | Остаток против 3DCoat |
|---|---|---|---|
| 0 plane | ортогональная проекция на ту координатную плоскость (XY, YZ или XZ), ось которой ближе всего к средней нормали острова (взвешенной площадями) | `plane` (`axis_plane`) | 0,000 на 9 сетках, включая дугу и острова головы — точно |
| 1 LSCM | наименьшие квадраты конформного отображения (Lévy и др., 2002): сохраняет углы, площадь плывёт | `lscm` | 0,000–0,010 на тестовых; 0,05–0,45 на островах головы |
| 2 ABF | по углам (angle based flattening, Sheffer и de Sturler, 2001): углы как у LSCM, площадь тянет меньше | `abf` | 0,000–0,015 на тестовых; 0,011–0,178 на голове |
| 3 GU | «globally uniform», близко к ARAP (Liu и др., 2008): треугольники почти жёсткие, площади ровные | `arap` | 0,000–0,026 на тестовых; 0,018–0,146 на голове |
| 4 Stripe | развёртка полосы | нет | выход из одних нулей даже на настоящих полосах из треугольников (тупик) |

`flattenSingleIsland` нумерует вершины и грани заново и может разделить вершины на шве. Ориентация и масштаб произвольные: опция `scale_to_geometry` даёт масштаб 3D.

**Копия ARAP** (`coat_algos.arap`):
1. Старт — LSCM, отражённый, если у большинства треугольников он вывернут.
2. 20 итераций «локально-глобально». Локальный шаг для каждого треугольника ищет ближайший поворот; глобальный решает систему с котангенсными весами. Матрица разложена один раз.

**Что выбрать для другой модели:**
- **ARAP / GU** — ровная плотность текселей внутри острова. На островах головы искажение площадей у него 0,036–0,039, у LSCM 0,41–1,65.
- **LSCM** — сохраняет углы и быстрее. Но длинный кусок (хвост, шея) тянет по площади до 5 раз.
- **ABF** — углы точнее, чем у LSCM, площадь ровнее; медленнее (Ньютон по углам, 10 итераций).
- **plane** — только для почти плоских кусков (лицо спереди).

**Копия ABF** (`coat_algos.abf`):
1. Неизвестные — углы треугольников. Желаемые углы — углы в 3D; у внутренних вершин они масштабируются, чтобы сумма была 2π. Вес угла — 1/угол².
2. Ограничения: сумма углов треугольника π, сумма углов у внутренней вершины 2π, условие колеса — произведения синусов по кругу вершины равны.
3. 10 шагов Ньютона по системе Лагранжа.
4. UV строится по углам LSCM: длины сторон по теореме синусов.

**`uv_unfold.py`** заново разворачивает острова, которые легли сами на себя. Метод задаётся `UNFOLD=lscm|arap`, по умолчанию lscm, сравнение на hero1 (`fix2/solid_auv.obj`) ниже. У ARAP каждый кусок ровнее, но куски сложенной трубки хвоста чаще накладываются, их режут повторно, и мелких островов становится больше.

| Режим | Островов | Граней поверх себя | Заполнение | uv_score |
|---|---|---|---|---|
| lscm | 397 | 15 | 0,597 | **2,40** |
| arap | 426 | 26 | 0,586 | 2,06 |

## Auto Seams + Unwrap (кнопки `$AutoEdges`, `$Unwrap`)

Правило разрезов воспроизведено только для угловатых форм (см. «Правило островов» ниже). Ниже — что измерено на выходе (`coat_probe.py seams fix2/solid_auv.obj fix2/parts_amid/parts.npy`, голова hero1, 19 994 грани).

**Где режет:**
- Разрезы идут по острым рёбрам: средний двугранный угол на разрезе 48,6°, по всем рёбрам 18,6°.
- Разрезы — 4,9 % длины всех рёбер.
- Больше всего разрезов на ушах: 0,40 стороны шва на грань.

**Какие острова получаются:**
- Всего 230 островов, из них 192 — осколки меньше 10 граней на острых складках.
- Большие острова из-за осколков дырявые: эйлерова характеристика от −9 до −31, то есть это не диски.

**Как разворачивает.** Три самых больших острова развёрнуты почти как проекция на плоскость:

| Сравнение | Остаток |
|---|---|
| против plane | 0,012–0,036 |
| против ARAP | 0,044–0,12 |
| против LSCM | 0,19–0,52 |

Искажение у них: углов 0,28, площадей 0,21.

**Откуда наложение на хвосте.** Острова, которые в 3D свёрнуты трубкой (шея плюс хвост), проецируются почти на плоскость. Поэтому одна сторона трубки ложится на другую. Переразвёртка ARAP или LSCM без новых разрезов наложение не убирает: остров действительно сложен в 3D. Нужны разрезы — их делает `uv_unfold.py` (`head_seams.split_folds`).

**Что из этого следует для другой модели:**
1. После Auto Seams проверять наложение (`head_seams.uv_overlap`).
2. Свёрнутые острова резать `uv_unfold.py`.
3. Если осколков много, свои разрезы по частям (`head_seams.py`) обычно лучше.

**Правило островов** (probe2, `coat_probe.py make2`: призмы с 3, 6, 12, 24 гранями, сфера, тор, куб):
- нормали внутри острова отходят от средней нормали острова не больше чем на 45–60°;
- острые рёбра режутся всегда: средний двугранный угол на разрезе призм 80–100°.

| Сетка | Островов у 3DCoat | У `charts` | Совпадение граней |
|---|---|---|---|
| призма 3 | 5 | 5 | 1,00 |
| куб | 6 | 6 | 1,00 |
| призма 6 | 6 | 6 | 0,91 |
| призма 12 | 6 | 6 | 0,75 |
| призма 24 | 6 | 6 | 0,79 |
| сфера | 6 | 6 | 0,73 |
| тор | 2 (конус до 79°) | 6 | 0,75 |
| голова | 230 | 607 | 0,17 |

**Копия `coat_algos.charts`** — вариационная аппроксимация формы (VSA, Cohen-Steiner и др., 2004):
1. Шесть стартовых областей по осям ±X, ±Y, ±Z.
2. Каждая область растёт по граням с наименьшей ошибкой нормали и никогда не переходит острое ребро (больше 60°).
3. Нормали областей пересчитываются, 15 итераций.
4. Каждая связная часть области — остров.

Для коробок, призм и сфер это даёт острова 3DCoat. Тор и органика (голова) режутся иначе, правило там не найдено. На 20 тыс. граней Python-версия работает больше 10 минут.

## uv.pack — упаковка (копия близкая)

Измерено (probe2: 24 прямоугольника и атлас hero1 после `uv_unfold`):
- отступ от края листа — 0,01;
- плотность текселей одинаковая у всех островов: разброс 1e-5 на прямоугольниках;
- без поворота заполнение 0,772, щели около 0,0036; с поворотом — 0,81, минимальная щель 0,0014;
- атлас hero1: заполнение 0,597 → 0,670; островов 397 → 404 (несколько островов разрезано); разброс плотности текселей 0,18 → 0,225 — 3DCoat немного масштабирует острова.

Копия — `coat_algos.pack`: xatlas с готовыми островами, полный перебор (`bruteForce`), отступ 2 пикселя из 2048.

| Настройки xatlas | Прямоугольники | Атлас |
|---|---|---|
| отступ 4, без перебора (как было в `uv_unfold`) | 0,763 | 0,607 |
| отступ 2, без перебора | 0,789 | 0,630 |
| отступ 2, перебор | 0,843 | 0,673 (33 с) |
| отступ 2, перебор, `blockAlign` | 0,867 | 0,660 |
| 3DCoat, с поворотом | 0,81 | 0,670 |

## Mesh.weld и reduceToPolycount (копии)

**weld(rel)** сливает вершины ближе rel × диагональ габаритов и удаляет вершины без граней. На сфере, разрезанной по экватору со щелью 0,001 или 0,01 (диагональ габаритов 3,46), число вершин у копии `coat_algos.weld` совпало с 3DCoat во всех 6 случаях (690 или 642).

**reduceToPolycount(N)** — схлопывание полурёбер: все вершины выхода — вершины входа, число граней ровно N. Копия `coat_algos.reduce` — quadric-схлопывание pymeshlab без оптимального положения, оно тоже оставляет вершины входа.

Средняя ошибка формы (шумная сфера на 1280 граней, в долях радиуса):

| Граней | 3DCoat | pymeshlab | fast_simplification (двигает вершины) |
|---|---|---|---|
| 640 | 0,0057 | 0,0077 | 0,0067 |
| 200 | 0,0178 | 0,0211 | 0,0199 |

## Объёмные инструменты (измерено, probe3, плотность 40)

- **Плотность** `density` — число вокселей на единицу сцены. Длина ребра получается ≈ 1/плотность (0,024 при 40). Плотность по умолчанию около 1, и голова единичного размера становится кубом из 8 граней.
- **closeHoles(size)** — параметр ни на что не влияет: дыры закрывает уже переход в воксели. Размеры 5, 20 и 60 дают одинаковый выход; круглые дыры радиусом 10°, 20° и 35° на сфере закрыты, сетка замкнута.
- **relaxVoxels(n)** — разброс радиуса 0,040 → 0,027 (1 шаг), 0,025 (3), 0,021 (10); сфера слегка усаживается.
- **relaxSurface(d)** (поверхностный объём) — топология сохраняется. Сдвиг почти радиальный и близок к `Mesh.relax` со степенью ≈ 0,7·d: при d 0,5 → 0,35 остаток 0,0024, при 2 → 1,3 остаток 0,0036. Копия — `coat_algos.vrelax`.
- **fromVolumeWithMaxPolycount(N)** — ровно N граней, шум поверхности сохраняется.

## Как применить к другой модели

| Шаг | Чем |
|---|---|
| сгладить область без усадки | `head_tools.py … open_relax degree=1 tangent=1` (= 3DCoat relax) или `relax` (Taubin) |
| развернуть кусок | `coat_algos.py flatten in.obj out.obj arap` (= GU), `abf` или `lscm` |
| острова для угловатой модели | `coat_algos.py charts in.obj islands.npy` (≈ Auto Seams) |
| упаковать UV | `coat_algos.py pack in_uv.obj out_uv.obj` (≈ uv.pack) |
| слить вершины, упростить | `coat_algos.py weld in.obj out.obj 0.0001`, `reduce in.obj out.obj 5000` |
| UV целиком от 3DCoat | `coat_run.sh in.obj out.obj auto` (Windows) → `uv_unfold.py` (разрезать наложения) → `uv_score.py` |
| UV без 3DCoat | разрезы `head_seams.py` по частям → xatlas, или `uv_unfold.py` поверх любой UV |
| проверить новый инструмент 3DCoat | добавить операцию в `coat_autouv.probe` и тестовую сетку в `coat_probe.make`, затем `run` и `analyze` |

## Тупики

- **LSCM на островах головы** не совпал с 3DCoat (остаток 0,05–0,45), хотя на тестовых сетках совпадает до 0,010. Проверены закрепления двух вершин:
  - наше: нижняя вершина и самая дальняя от неё;
  - концы диаметра края;
  - концы оси габаритов.

  Ни одно не объясняет расхождение: head0 0,178–0,212, head2 0,452–0,480. Вероятно, 3DCoat решает LSCM иначе (спектрально или итерациями с другой остановкой), а на дырявых сложенных островах решение плохо обусловлено. Прямое решение и lsqr дают один и тот же наш LSCM, значит, дело не в сходимости.
- **ARAP вместо проекции** не убирает наложение у свёрнутых островов (см. выше).
- **ARAP в `uv_unfold`** дал больше мелких островов и худший uv_score (2,06 против 2,40). Поэтому по умолчанию остался LSCM.

## Чего ещё нет

План по этим пунктам — `docs/coat-tools-plan.md`.

- Stripe (метод 4): 3DCoat отдаёт одни нули, копировать нечего.
- Правила Auto Seams для органики и замкнутых трубок (тор, голова): `charts` там режет иначе.
- Открытых копий `relaxVoxels` и ремеша. Возможный путь — воксели и marching cubes из scikit-image.
- Упаковки через 3DCoat в `uv_unfold.py` (режим `pack` пока есть только в `probe`); `uv_unfold` пакует xatlas без перебора.
- LSCM на дырявых островах головы (см. «Тупики»).

- В `probe1/probe/*.obj` — входы и выходы 3DCoat (`*_f0..4.obj`, `*_r<степень>_<tangent>_<crease>.obj`), `probe.txt` — список задач.
