# Бэклог (не приоритет)

Отложенное, чтобы не терять. Статусы пунктов плана — в `docs/gaps-plan.md`.

## 1. Экран `trade` и тест `screens` — сделано

Тест падал не из-за торговли: тур не открывает экраны через `Screen_Open`, а обработчик `ievnt_command` меню уходит вместе с меню, поэтому клики никому не доходили; к тому же под туром нет города (`townIsland` пуст). `Screen_TourTrade` ставит обработчик `Screen_Command` и подставляет магазин Хайрока (наше, только для теста). `screens` PASS, в логе куплено/продано.

## 1a. Магазин по оригиналу — сделано

Склад, цены, экспорт/импорт и количество по `TOWN.dll`. Репутация в цене и случайная поправка при равных ценах перенесены (цены фиксируются при открытии). Множитель цены острова — сделан (третье число `type` острова). Открыто: игровая дата (у нас +15 дней за визит), кнопки PrevShip/NextShip (смена корабля флота), скрытие кнопок до выбора режима, артефакт «чёрная полоска с символами» в оригинале (гипотеза H7: скрытые кнопки Отмена; не проверено, нет сейва — см. corsairs-original-fix/docs/click-input-research.md).

## 2. Остальные экраны (раздел 2 плана)

По очереди: `sship`/`sgoods`/`schest`, `crew`/`tavern`, `shipexchange`/`transfer`, `logbook`, `mainmap`. На каждый:
1. список узлов `.ini`, которым `Screen_Value` не даёт значения (пустые на кадре);
2. данные брать конвертером `tools/pdm_*.py` из оригинала, код — в `screens.c`;
3. кадр, автотест (`autotest/scenarios.txt`, `docs/autotests.md`), запись в `docs/original-vs-remake.md` и `docs/gaps-plan.md`.

Список типов верфи по `<остров>.sht` — сделано. `crew`/`tavern`: диалог их не открывает (см. `docs/decompile.md`, «Таверна и найм команды»), сначала найти, кто их запускает.

## 3. Верфь — отложенное

- «Обшить корпус» (кнопка 4): в оригинале ничего не делает (обработчик — пустая ветка, режим «Sheathe cost» недостижим), кнопка скрыта. Закрыто, см. `docs/decompile.md`.
- Формат скорости и маневренности — сделано (`%.1f`).
- «Починить», «Полностью» и шаг стрелок ± — сделано (`docs/original-vs-remake.md`).
- Формула цены ремонта и продажи — сделано (`docs/decompile.md`); навык № 2 и поле `+0x3d8` в цене.

## 4. Шрифты и выравнивание (1.12)

Оригинальных TTF (`seadogs10..13.ttf`, `seawolf`, `log-russ`, `Interface`) в папке игры нет; стоят заменители (наше). На кадре верфи: пробелы в правой колонке схлопнуты, значения слева не выровнены. Windows-машина пользователя с шрифтами 2026-10-30 недоступна по ssh. План: взять файлы через `PDM_FONTS`, иначе подобрать ширину пробела и выравнивание узлов по `.ini` оригинала.

## 5. Грабёж — отложенное (кадры 2026-10-30)

- `shipexchange`: левая колонка (свой корабль) заполнена; в `ransack.ini` нет узлов значений для правой колонки (только подписи `s_ship15..28`), значит значения захваченного корабля dll рисует сама, адреса — `RANSACK.dll` около 0x10006ef0 (показ корабля, «%.0f%%», «(%d/%d %s)»). Заголовки «Текущий корабль»/«Захваченный корабль» (`lb_CurrentShip`, `lb_TargetShip`) на кадре пусты.
- `transfer`: список товаров героя, вес и вместимость заполнены (кадр проверен); правый список берётся из `PrizeShip.cargo`, пока его никто не заполняет (приз без трюма); прокрутки нет (видны первые 10 строк), кнопок переноса нет, подпись правого корабля пуста.
